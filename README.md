# 🍱 ربات تلگرام سامانه تغذیه امیرکبیر (AUT Food Bot)

ربات شخصی تلگرام برای مدیریت، مشاهده برنامه غذایی، یادآوری ددلاین‌ها و رزرو خودکار غذای دانشگاه صنعتی امیرکبیر (`food.aut.ac.ir` / `samad.aut.ac.ir`).

## 🎯 اهداف پروژه
- مشاهده منوی هفتگی و روزانه سلف‌های دانشگاه (سلف مرکزی، مکمل، پلی‌فود و...)
- یادآوری مهلت رزرو و جلوگیری از سوختن ژتون غذا (۴۸ ساعت قبل)
- رزرو خودکار وعده‌ها بر اساس ترجیحات هفتگی دانشجو
- اعلام مانده حساب و هشدار کمبود شارژ

## 🏗 ساختار پروژه
- `src/food/`: کلاینت وب‌سرویس و ارتباط با سامانه تغذیه
- `src/bot/`: روتر و هندلرهای ربات تلگرام
- `src/telegram/`: ارتباط با Telegram Bot API و قالب‌بندی فارسی
- `src/crypto.ts`: رمزنگاری AES-GCM و امنیت اطلاعات
- `tools/`: ابزارهای دیپلوی و راه‌اندازی محلی

*پروژه شخصی و دانشجویی، مستقل از دانشگاه صنعتی امیرکبیر.*
